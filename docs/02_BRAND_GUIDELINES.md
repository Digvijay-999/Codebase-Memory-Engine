# ContextForge Brand Guidelines

## Brand Overview

**Product Name:** ContextForge

**Tagline:** Forge understanding from any codebase.

ContextForge is an AI-powered code intelligence platform that helps developers understand unfamiliar codebases through Retrieval-Augmented Generation (RAG).

The brand should communicate intelligence, precision, clarity, and craftsmanship.

---

# Brand Personality

ContextForge should feel:

- Premium
- Calm
- Intelligent
- Minimal
- Technical
- Trustworthy
- Modern

It should never feel:

- Flashy
- Cyberpunk
- Gaming-oriented
- Cartoonish
- Overly futuristic
- Like a generic SaaS template

---

# Design Inspiration

The visual language should draw inspiration from:

- Apple
- Linear
- Cursor
- Arc Browser
- Nothing

These products share:

- Excellent typography
- Intentional whitespace
- Subtle animations
- Calm interfaces
- High perceived quality

---

# Color Rules

Use accent colors only for:

- Primary CTA
- Active navigation
- Logo highlights
- Focus states
- Loading indicators
- Interactive highlights

Avoid large chrome-colored surfaces.

The interface should remain predominantly dark.

- Clean spacing

## Body Style

- Comfortable reading width
- Medium line height
- High contrast
- Never overly condensed

---

# Iconography

Use Lucide icons throughout the application.

Icons should be:

- Minimal
- Consistent
- Thin
- Functional

Avoid filled icon sets.

---

# Logo

The logo should be inspired by the concept of infinity and connected knowledge.

It should represent:

- Continuous learning
- Context
- Intelligence
- Connected systems

Do not use a literal infinity symbol.

Prefer a clean geometric mark that is recognizable even at small sizes.

---

# Hero Centerpiece

The hero should feature a configurable centerpiece.

Initially this will use the Splite component with a Spline scene.

The scene should feel:

- Minimal
- Premium
- Calm
- Intelligent

The implementation should allow the scene to be replaced later without changing the page layout.

---

# Motion Philosophy

Motion should support understanding.

Animations should never exist purely for decoration.

Inspired by:

- Apple
- Linear

Use:

- Fade
- Scale
- Blur
- Translate

Avoid:

- Bounce
- Excessive rotation
- Flashing effects
- Distracting motion

---

# Layout Philosophy

Whitespace is a design element.

Every section should breathe.

Prefer fewer elements with better spacing over crowded layouts.

Maintain a maximum content width of approximately 1280px.

---

# Visual Principles

Every screen should communicate:

- Confidence
- Precision
- Simplicity
- Intelligence

Users should immediately recognize ContextForge as a premium developer tool—not a generic AI chatbot.

The product should feel cohesive across every page, with consistent spacing, typography, colors, and motion.
